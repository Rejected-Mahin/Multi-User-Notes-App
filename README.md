# Multi-User-Notes-App
This is an Multi user notes app. Here users can create and edit notes. But first, they have to register and use their credentials to log in. 

Steps to Run the App:
1. First run the app
2. Set username & password
3. Click "Register"
4. Give username & password
5. Click "Login"
6. In the right side text box write your note.
7. Click add
8. Click save
9. The left side text box will show the note with serial number.

you can edit the notes by clicking the note on left text box. and after editing click Save.
